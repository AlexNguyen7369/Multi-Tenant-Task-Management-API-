Suggested manual test script

  1. Register a user, then Login.
  2. Create Workspace A, click Use on it.
  3. Create a Board and a Task inside it — both should succeed (member of A).
  4. Create Workspace B, click Use on it — the Boards/Tasks lists should go empty even though A's data still exists.
  5. Click Use back on Workspace A — its board/task reappear. This is the tenancy isolation guarantee from skeleton_phaese1.md §3 working end to end.
  6. Register a second user, log in as them, try Refresh list on Workspace A's boards without ever calling "Use" on A — expect 403 in the log (not a member).
